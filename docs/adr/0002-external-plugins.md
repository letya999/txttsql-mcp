# ADR-0002: внешние пакеты плагинов

Статус: принято, 2026-09-23. Дополняет ADR-0001.

Помимо встроенных адаптеров сервер принимает два независимых вида плагинов: источники БД и провайдеры метаданных. Каждый пакет содержит `plugin.json` и исполняемый файл. Манифест явно подключается в `config.toml`; пакет запускается как дочерний процесс с версионированным протоколом JSON lines. Это позволяет выпускать новые адаптеры без перекомпиляции Rust-сервера и избегает нестабильности ABI динамических библиотек.

Вызов `execute` получает только SQL после проверки центральным guard. Манифест объявляет поддерживаемый SQL-диалект, но расширение перечня диалектов требует изменения guard. Плагин обязан сам установить read-only ограничения на стороне БД. Установленный исполняемый файл обладает правами пользователя MCP-процесса, поэтому пакет считается доверенным. Протокол и примеры описаны в [документации](../operations/plugins.md).
