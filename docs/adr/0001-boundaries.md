# ADR-0001: границы доверия и расширения

Статус: принято, 2026-09-22.

Новые SQL движки подключаются реализацией `DatabaseAdapter`, новые каталоги — `MetadataAdapter`. Каждая реализация получает только свой конфиг и креденшел. MCP handler не открывает произвольные URL и не выполняет SQL мимо guard. Такой реестр даёт расширяемость без загрузки непроверенного динамического кода.

Синтаксический guard дополняется read-only правами БД: парсер не способен доказать отсутствие побочных эффектов у всех функций и представлений. Невалидный или неподдерживаемый SQL отклоняется. Пустой allowlist закрывает доступ к таблицам. SQL и тексты вопросов записываются лишь при явном включении памяти.
