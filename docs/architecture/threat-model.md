# Модель угроз

MCP-клиент может передать произвольный SQL, текст поиска, имя источника и идентификатор метаданных. Конфигурацию и путь к broker задаёт оператор; они считаются доверенными. Удалённые БД, OpenMetadata, Airflow и файлы онтологии находятся вне процесса MCP. SQLite memory может содержать SQL, вопросы и карточки с чувствительным контекстом.

| Риск | Граница |
| --- | --- |
| SQL-запись или чтение чужой таблицы | Один SELECT, обход вложенного AST, квалифицированные имена, allowlist на источник; дополнительно read-only транзакция/ClickHouse `readonly=1` и отдельная роль с `SELECT` только на нужные таблицы. |
| Обход allowlist через кавычки или регистр | Кавычки в именах физических таблиц и функций запрещены. Для ClickHouse сравнение имён строгое, для PostgreSQL/CockroachDB учитывается приведение некавыченных идентификаторов к нижнему регистру. |
| Утечка учётных данных | В TOML только ссылки `env`/`file`/`broker`; секреты ограничены 8 КБ, broker запускается без shell и с таймаутом, HTTP redirect отключён, stdout зарезервирован для MCP. |
| Перегрузка БД/процесса | Лимит строк, таймаут запросов, лимиты размера HTTP-ответа, размер PgPool и семафор запросов ClickHouse для каждого источника. |
| Утечка через память/онтологию | Запись памяти выключена по умолчанию. Файл SQLite хранится в приватном томе. Чтение онтологии ограничено типами файлов, размерами и путём корня; JSON-графы читаются с проверкой границы каталога. |
| Ненадёжные внешние метаданные | OpenMetadata/Airflow доступны только через настроенные HTTPS origin URL, с ограничением размера ответа и без redirect; Bearer/Basic учётные данные разрешаются из ссылок на секреты, данные возвращаются как данные, не как инструкции. |

Остающийся риск: разрешённый `SELECT` может вызвать побочные эффекты пользовательских функций/представлений или дорогое сканирование. Оператор должен выдать минимальные привилегии и лимиты ресурсов самой БД, а также ограничить сетевой доступ MCP. Проверки на локальных контейнерах доказывают поведение протестированных версий, но не заменяют ревизию прав и функций конкретного сервера.
