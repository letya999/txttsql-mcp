# Безопасность

Сообщайте об уязвимостях владельцу проекта приватно. Не прикладывайте SQL с персональными данными и реальные токены к публичным отчётам.

SQL-парсер и allowlist — первая граница. Имена физических таблиц должны быть в форме `schema.table`; кавычки в именах запрещены. Обязательная вторая граница: роли PostgreSQL/CockroachDB без прав записи и ClickHouse профиль `readonly=1` с `GRANT SELECT` только на нужные таблицы; настройте их до подключения MCP. ClickHouse запрос также передаёт `readonly=1`, но права роли должны быть ограничены независимо. Ограничьте сеть до нужных БД и сервисов метаданных. Не считайте пользовательский `SELECT` полностью безвредным: функции, представления и политики доступа зависят от сервера.

Не сохраняйте пароли и токены в TOML. Используйте переменные окружения, секреты в файлах с ограниченными правами или broker. Доверяйте только конфигу из контролируемого каталога: `broker.program` запускает указанную программу без shell. Memory SQLite содержит SQL, вопросы и кешированные метаданные; храните файл в приватном томе.
