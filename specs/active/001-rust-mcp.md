# Rust MCP для аналитических источников

Требования пользователя: один Rust MCP должен одновременно обслуживать много именованных PostgreSQL, CockroachDB и ClickHouse подключений; валидировать SQL и запрещать опасные операции; брать секреты из хранилища или broker; опционально сохранять проверенные запросы и метаданные; подключаться к OpenMetadata и понимать Airflow DAG; позволять добавлять БД и источники метаданных; иметь тесты, линтеры, защитные границы, Git и Docker. Источник семантических правил — `txttsql`; структура документации — `memory_bank_setup`.

Критерии приёмки: компиляция и тесты проходят, MCP клиент получает и вызывает инструменты, каждый настроенный источник независим, опасные SQL отклонены до сети, БД дополнительно ограничивает запись, секреты не попадают в код/логи/артефакты, опциональные интеграции работают при конфигурации, Docker образ собирается и запускается с внешним конфигом и секретами. Живые проверки трёх БД и сервисов метаданных требуют тестовые endpoints.
